Electrodialysis — Mass Balance & Energy Calculator

Preliminary sizing tool for SonixED™ ED systems. Enter the feed water, pick the sizing mode and the membrane types, and the tool estimates stage count or stack circulation, the ion split between product and concentrate, and the energy envelope. All outputs include ±10% engineering tolerance.

Input parameters

Technical configuration

θ is the transport of a divalent ion relative to a monovalent ion of the same sign: 1.0 means it moves as fast, 0 means it stays in the product. The 0.15 defaults are a provisional assumption, not measured Hydrovolta data — set them from the membrane datasheet or pilot results before an output leaves the building.

Feed ion composition

The split is normalised to the permeate inlet salinity above, so the entered numbers set the ratio between ions and the inlet salinity sets the total. Flow diagram

Equations used

Q_total = Q_permeate / (RR / 100)
Q_reject = Q_total − Q_permeate
Feed split = entered ion concentrations normalised so that ΣCi = C_in
θi = 1 for monovalent ions; θc or θa for a divalent ion facing a monovalent-selective membrane
Ci(f) = Ci,feed × fθi, where f is the monovalent fraction left after a stage pass (f = 0.5n)
Auto-size: solve ΣCi(f) = C_out for f, then N = ceil(log&sub2;(1/f))
Fixed stacks: passes P = ceil(N / stacks)  ·  circulation ratio = P  ·  stage passes = stacks × P
C_concentrate,i = (Q_total × Ci,feed − Q_permeate × Ci,product) / Q_reject
E_stage (kWh/m³) = [ (0.0635 / 0.92) × 0.001 × TDS_inlet + 0.10033 ] × 1.2
E_total (kWh/h) = Σ E_stage(i) × Q_permeate

Preliminary estimates only — ±10% engineering tolerance applied. Contact Hydrovolta for site-specific engineering assessment.
