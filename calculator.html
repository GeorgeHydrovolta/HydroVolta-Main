Equations used

Q_total = Q_permeate / (RR / 100)
Q_reject = Q_total − Q_permeate
C_reject = (Q_total × C_in − Q_permeate × C_out) / Q_reject
N_stages = ceil( log&sub2;(C_in / C_out) )
C_stage_n: inlet = C_in / 2&sup(n−1)  ·  outlet = C_in / 2⊃n
E_stage (kWh/m³) = [ (0.0635 / 0.92) × 0.001 × C_inlet + 0.10033 ] × 1.2
E_total (kWh/h) = Σ E_stage(i) × Q_permeate
