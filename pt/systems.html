Sistemas

Pilotos em contentor. Sistemas de projeto quando os dados sustentam a escala.

Até 95 % de recuperação numa única passagem em água subterrânea salobra, a 1–3 g/L.

O SalinBloc™ é a plataforma modular normalizada da Hydrovolta para pilotos, instalação distribuída e validação por fases. Os sistemas de grande escala montados em skid são projetados depois de os dados do local confirmarem o caso técnico e comercial. Ambas as vias integram o tratamento SonixED™ e, quando necessário, a valorização da salmoura a jusante.

Por dentro do sistema

Equipamento real. Em operação no terreno.

Cada unidade SalinBloc™ contém a linha de tratamento SonixED™ completa, os sistemas de controlo e o equipamento de telemetria. Não são imagens de síntese nem protótipos — são sistemas em funcionamento a gerar dados reais de desempenho.

Percurso de implementação

Validar antes de ampliar. Sempre.

O piloto SalinBloc™ não é um produto para vender — é um instrumento de redução de risco para quem compra. Gera um conjunto de dados de desempenho do próprio local que nenhuma ficha técnica substitui. A ampliação é projetada a partir desses dados.

01

Análise de água

Química da origem analisada. Adequação técnica avaliada. Decisão GO / NO-GO tomada antes de se especificar equipamento.

02

Projeto do piloto

SalinBloc™ configurado para a sua origem. CAPEX/OPEX comparados. Via de financiamento identificada.

03

Piloto no local

SalinBloc™ colocado em serviço com monitorização completa. Dados reais de operação gerados. Potencial de valorização da salmoura avaliado em paralelo.

04

Ampliação

Instalação completa projetada a partir dos dados do piloto. Unidades SalinBloc™ em paralelo ou skid à medida — apenas quando os dados o sustentam.
